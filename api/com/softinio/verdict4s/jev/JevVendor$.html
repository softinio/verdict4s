JevVendor

com.softinio.verdict4s.jev.JevVendor
object JevVendor extends Vendor

TypeSafe AI's Jev.

POST https://api.typesafe.ai/v1/systemone
{"state": ..., "model": "jev-latest", "questions": {"q00": {"type": "noul", ...
}}}

Jev accepts everything the shared question model can express, so it adds no validation of its own. It is also the only vendor with a models endpoint, which is why modelsUrl and parseModels live here rather than on com.softinio.verdict4s.Vendor.
